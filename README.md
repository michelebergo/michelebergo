# Hi, I'm Michele 👋

I build open-source tools for **astrophotography automation** and **home automation** — mostly around [N.I.N.A.](https://nighttime-imaging.eu/) and ESP32/ESPHome.

## 🔭 Astrophotography

- **[AI Assistant for NINA](https://github.com/michelebergo/nina.plugin.aiassistant)** — chat with your imaging rig: multi-provider AI (Claude, GPT, Gemini, Mistral, Ollama) with MCP equipment control
- **[AI Weather for NINA](https://github.com/michelebergo/nina.plugin.aiweather)** — AI-based cloud detection from all-sky cameras as a NINA safety monitor
- **OAPA** — open universal protocol for motorized polar alignment platforms, integrated in the official Three Point Polar Alignment plugin ([INDI driver](https://github.com/michelebergo/indi-oapa))
- **[NINA MCP Server](https://github.com/michelebergo/nina_mcp_server)** — control NINA from any MCP-capable AI client
- **[nina.autopilot](https://github.com/michelebergo/nina.autopilot)** — orchestrator dashboard for fully automated imaging sessions

## 🏠 Home automation

- **[samsung_ac](https://github.com/michelebergo/samsung_ac)** — Samsung HVAC integration
- **[esp8266-comfoair-mqtt](https://github.com/michelebergo/esp8266-comfoair-mqtt)** — Zehnder ComfoAir ventilation over MQTT
